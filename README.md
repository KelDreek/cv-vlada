# Vladislav Fidrik — portfolio

Локальная реализация Portfolio 2026 из Figma: главная и два кейса, версии для компьютера и телефона, плавная навигация с восстановлением прокрутки и фокуса. Проект не опубликован.

## Запуск и проверки

```bash
npm install
npm run dev
```

Адрес для просмотра: [http://127.0.0.1:5173/](http://127.0.0.1:5173/).

```bash
npm run check
npm run check:assets
node scripts/verify-originals.mjs
npm run build
npm run preview
```

`verify-originals.mjs` сравнивает локальные файлы с байтами исходного `.fig` и сохраняет результат в `outputs/verification/source-integrity.json`. Успешно проверены 69 изображений, 12 видео, исходный MP3 и обе GIF-анимации. Проверка байтов не является сертификацией попиксельного совпадения интерфейса.

Сборка находится в `dist/`. После сборки автоматически создаются отдельные входные файлы для `/case-study-1/` и `/case-study-2/`, поэтому обновление страниц работает на статическом хостинге без серверных правил перенаправления.

## GitHub Pages

Репозиторий: [KelDreek/cv-vlada](https://github.com/KelDreek/cv-vlada). Публикация настроена в `.github/workflows/pages.yml`: после отправки изменений в `main` GitHub устанавливает зависимости, собирает сайт и публикует только `dist/`. Исходные `.fig`, `.pen`, рабочие файлы и отчёты не входят в публикуемую папку сайта.

При первом запуске в Settings → Pages необходимо выбрать Source → GitHub Actions. Ожидаемый адрес после успешной публикации: `https://keldreek.github.io/cv-vlada/`.

Workflow получает базовый адрес из настроек Pages. Изображения, шрифты, видео и внутренние переходы учитывают подпапку репозитория. Для локальной проверки такой сборки:

```bash
PAGES_BASE_PATH=/cv-vlada/ npm run build
PAGES_BASE_PATH=/cv-vlada/ npm run preview
```

Обычный `npm run dev` продолжает работать по адресу `http://127.0.0.1:5173/`.

## Исходный дизайн

- `design/portfolio.fig` — сохранённая без изменений копия исходного файла Figma.
- `design/portfolio-original.pen` — основной редактируемый импорт: три раздела, шесть экранов, 12 переиспользуемых компонентов и 66 ссылок на них.
- `design/original-assets/` — все 69 исходных изображений и исходный MP3.
- `design/portfolio.pen` и `design/images/` — резервная реконструкция предыдущего прохода.
- `design/source/` — сохранённые исходные композиции страниц.

Для повторного разбора исходного архива:

```bash
node scripts/import-fig.mjs design/portfolio.fig
```

Скрипт использует `openfig-core`, извлекает материалы и создаёт `work/figma-original/import-trees.json` и `outputs/verification/fig-import.json`. Он сам не сохраняет `.pen`: основной файл `portfolio-original.pen` был создан из деревьев импорта и сохранён через pen.dev MCP.

## Приложение и медиа

- `src/pages/` — шесть композиций; маршруты `/`, `/case-study-1`, `/case-study-2`.
- `src/components.tsx`, `src/main.tsx` — медиа, ссылки, маршруты, переходы и восстановление позиции/фокуса.
- `src/styles.css`, `src/design.css` — общие стили и значения из макета.
- `public/assets/`, `public/fonts/` — статические материалы и основные локальные Averia Serif Libre Light / Bold Italic.
- `public/media/` — 12 оригинальных MP4 и две настоящие GIF; 10 уникальных видео видимы на шести экранах, игровой ролик используется повторно, ещё два исходных видео сохранены без добавления в видимую композицию. PNG-кадры используются при уменьшении движения.
- `public/lettering/english.svg`, `polski.svg`, `in-progress.svg` — точные контуры исходных надписей, без зависимости от файла шрифта. Флаги — PNG из Apple Color Emoji. В основном `.pen` надписи сохранены как векторные пути.
- `design/media-sources.json` — соответствие видео исходным идентификаторам; `npm run media` обновляет манифест приложения. Перед запуском и сборкой он обновляется автоматически.
- `outputs/VERIFICATION.md`, `outputs/verification/` — результаты и материалы проверки.

Обычные видео запускаются без звука и повторяются при появлении в области просмотра; учитывается предпочтение уменьшенного движения. Языковые ролики запускаются вручную со звуком через стандартные элементы управления и не играют со звуком одновременно. У GIF используется статичный вариант при уменьшении движения. Внешние ссылки ведут на реальные сервисы; само приложение и его материалы доступны локально.

Готовый кейс открывается нажатием в любой области карточки: на обложке, заголовке, описании или в промежутке между ними. При наведении, фокусе клавиатуры или нажатии обложка становится полупрозрачной, а текст — вторичного цвета. Карточки незавершённых проектов не ведут на другую страницу: наведение или фокус показывает исходную надпись «Case Study in Progress …» поверх размытой обложки. На устройствах без наведения статус постоянно виден компактной плашкой. Геометрия карточек и высота страницы сохранены.

## Точность и ограничения проверки

Сохранены исходные тексты, включая повторы, цвета, изображения и медиа. Свежий `outputs/verification/final-layouts.json` подтверждает совпадение высот всех шести экранов с исходными фреймами и отсутствие горизонтального переполнения и недостающих изображений на контрольных ширинах:

| Экран | Ширина, px | Высота, px |
| --- | ---: | ---: |
| Главная, компьютер | 1280 | 3384 |
| Главная, телефон | 399 | 3117.5 |
| Кейс 1, компьютер | 1280 | 20050 |
| Кейс 1, телефон | 375 | 18403.25 |
| Zuzuzoo, компьютер | 1280 | 10022 |
| Zuzuzoo, телефон | 375 | 9264.25 |

Проверка взаимодействий карточек сохранена в `outputs/verification/card-interactions.json`: семь точек готовой карточки принадлежат одной ссылке, нажатия на обложку и заголовок открывают соответствующие кейсы, нажатие на незавершённый проект не меняет адрес. Снимки состояний: `outputs/hover-ready.png`, `outputs/hover-progress.png`, `outputs/hover-mobile.png`. Это проверка указанных сценариев, а не всех возможных устройств.

В браузере проверено реальное воспроизведение `audio-creation` и двух языковых роликов; результат сохранён в `outputs/verification/browser-playback.json`. Это выборочная проверка воспроизведения, а не проверка всех роликов во всех браузерах.

Унаследованный цвет вторичного текста `#838074` даёт контраст около 3.79:1 на фоне страницы и 3.50:1 на вторичной поверхности. Он сохранён ради соответствия исходнику; соответствие AA и проверка всех браузеров не заявляются. Наличие оригинальных файлов и точных размеров не означает 100% попиксельную сертификацию.
